## What the tests prove (anti-gaming and negatives)

- Harness fallbacks: partial/invalid/negative/boolean context is ignored (`test_partial_or_corrupt_context_is_ignored_and_never_crashes`); junk pages/controls dropped (`test_inventory_export_is_an_allowlist_and_survives_junk`, includes a `typed text` value that must not appear); stale/other-session inventory, changed oracle, grounding contexts for an unknown operation are refused.
- Stricter, not looser: URL gate for both rules (`off_page_url`), ambiguity across scroll offsets earns nothing, a wrong scroll offset never credits, one offset cannot rescue another target (`target_mismatch`), path rule unchanged for A2 locators (`path_mismatch` for the wrong target), derived detection counts unmatched controls against precision and ignores other pages; the derived detection feeds the unchanged `metrics.score`.
- No sensitive text in the trace: only a scroll integer pair and a SHA-256 are added; inventory names are the same control labels the planner already stores; nothing about typed values.
- Combinations: `test_each_source_combination_scores_from_the_same_stored_data_without_collisions` (all vs none give C 2/6 vs 1/6 on one stored session, labelled artifacts, default `score.json` untouched), `parse_sources`/`artifact` validation, `detect --sources none|click_context` returns the old empty detection.

## How to benchmark each combination (no live run needed for A1/A3 re-scoring)
1. A session run with all flags on is stored once: `run.py import`, `collect` (writes `inventory.json` and `contexts`), or `ground` for evidence collected earlier.
2. `run.py detect --iteration I --sources inventory --label inv` (or `none`) writes `detection.derived.<label>.json`; pass it as `--detection`.
3. `run.py evaluate --iteration I --sources all|none|click_context|inventory|click_context,inventory --label <name> ... --detection <file>`; artifacts `score.<label>.json`, `assessments.<label>.json`, `detection.<label>.json`. Reviews are the same content-addressed ones; under a combination that cannot bind a click, the reviewer simply must not credit it (the harness raises `assessment binding does not match oracle (<reason>)`).
4. A2 is a live-session property (it changes which locator a click used and what the model saw): compare sessions run with and without it.
