## Continuation: deterministic viewport discovery

Implemented [ADR-020](../../../docs/adr/020-deterministic-viewport-discovery.md).
Prompt `codex-dom-v11` delegates viewport scanning to the controller. A DOM
`no_safe_action` or legacy scroll-only reply supplies no accepted action; the
model delta is discarded. Context-only revalidation checks the original document,
page, URL, scroll, private forms, visible context and scope before the controller
scans by 80% viewport height. Observation races get at most three bounded read-only
attempts; context changes fail immediately. Every refresh consumes existing
budgets. Physical prepare/execute guards remain intact.

The worker advertises `viewport-context-v1`, required at session open. API,
workflow worker, Playwright worker and Codex bridge were rebuilt and restarted
